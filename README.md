# Beads Studio · 拼豆工作室

纯浏览器端运行的拼豆设计工具，提供「图像规范化 → 像素编辑 → 颜色优化 → 图纸与用料导出」完整工作流。无后端上传，数据全部在本地浏览器计算。

---

## 核心流程

### 1. 规范化
将任意图像重采样转换为「1 像素 = 1 颗豆」的标准网格：
- **自动识别**：适用于像素画或正向拍摄图。基于方向投影自相关与基频栅格拟合，自动提取网格周期与相位。
- **四角变换**：适用于倾斜或透视照片。手动定位 4 个角点，通过双线性插值进行透视矫正与网格采样。
- **直接 1:1**：适用于原始像素图。自动检测整数倍放大并无损压回原始网格。

### 2. 像素编辑
在规范化网格上微调：
- 支持画笔、油漆桶（支持单色与色系聚类填充）、吸管工具。
- 支持设置透明格子（标记为忽略，不计入后续配色与用料清单）。
- 支持色板管理、取色器与撤销/重做（`Ctrl+Z` / `Ctrl+Y`）。

### 3. 颜色优化
将图中的目标颜色映射到真实拼豆色号库（如 MARD）：
- **模拟退火算法**：以加权 ΔE 最小化为目标搜索最优用色组合，采用增量距离维护保证秒级收敛。
- **明暗层次保留**：在目标函数中加入层次损失惩罚项，并配合同色系拆层，防止亮度过渡被过度压缩。
- **色数控制**：支持固定色数或根据收敛曲线自动探测最优色数；内置八叉树减色与候选色筛选。
- **多方案对比**：一键并行生成不同侧重点（省豆、均衡、保层次、原色优先）的方案供对比选择。

### 4. 图纸与导出
- **矢量渲染**：基于纯 SVG 绘制图纸，支持方格与仿真珠子样式、可调双级网格线、行列标尺与色号标注。
- **大图切板**：支持按拼豆板规格（如 50×50、52×52）自动拆分多页并排版。
- **全屏对图**：支持手势捏合缩放、拖动画布与屏幕常亮（Wake Lock），方便实际拼豆摆放。
- **多格式导出**：
  - 图纸：矢量 SVG、高分辨率 PNG（1× / 2× / 4× / 8×）、多页矢量 PDF。
  - 数据：1:1 像素图 PNG、用料清单 CSV、色号列表与 JSON 项目存档。

## 快速开始

```bash
npm install
npm run dev        # 启动本地开发服务 (http://127.0.0.1:5173/)
npm run build      # 构建生产产物到 dist/
npm run preview    # 预览构建产物
```

### 自动化测试

```bash
npm test           # 核心算法测试 (Node 环境)
npm run test:css   # CSS 层叠与 MD2 规范测试
npm run test:pwa   # PWA 清单与 Service Worker 校验
```

## 特性说明

- **离线支持 (PWA)**：完全支持安装为桌面/移动端独立应用，通过 Service Worker 离线运行。
- **多标签页与自动保存**：支持多项目标签并行切换，编辑进度实时同步至 localStorage，支持 JSON 导入导出备份。
- **标准色号支持**：内置 MARD、COCO、漫漫、盼盼、咪小窝等多套品牌色号对应表，支持标准 221 色与扩展 291 色。
- **半透明豆处理**：特殊色号（如 MARD H01）按实际透光观感进行图纸绘制与底板色彩拟合。

## 技术栈

- **框架**：React 19 + TypeScript + Zustand
- **构建**：Vite
- **界面规范**：Material Design 2 (Materialize CSS + Roboto + Material Icons)
- **核心算法**：纯 TypeScript 实现，无 DOM 依赖，支持同构运行
